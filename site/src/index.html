Two friends have watched football together for fifty years. Now Kassa no longer remembers Abebe. Abebe keeps taking him to the match anyway.

How it was made

It opens as a story about two friends and a football match. Then it shows you, gently, what dementia takes, and what it cannot.

The storyboard

Twelve shots, one contract.

Every picture, line and subtitle below is read from storyboard.json, the one file the whole film is built from.

    How it was made

    Not edited by hand. Built by a pipeline.

    One command rebuilds both films from the storyboard. Each stage caches its output under a hash of the exact request, so changing one line regenerates only that line.
